# Incident Management Operations Dashboard

## Project Objective
Build an operational analytics dashboard for monitoring IT service incidents, SLA performance, assignment workloads, and operational trends.

## Business Problem
Operations teams require visibility into ticket volume, workload distribution, recurring issue categories, and SLA compliance.

## Tools Used
- Power BI
- Power Query
- DAX

## KPIs Tracked
- Total Tickets
- Open Tickets
- Closed Tickets
- High Priority Incidents
- Average Resolution Time
- SLA Breach %

## Dashboard Features
- Incident trend monitoring
- Assignment group workload analysis
- Root cause analysis
- SLA breach analysis
- Resolution time analysis
- Interactive slicers and filtering

## Operational Insights
- Incident volume remained stable across most months
- High-priority incidents represent significant operational workload
- Multiple recurring issue categories identified
- SLA performance monitored dynamically using DAX calculations

## Future Improvements
- Real-time incident monitoring
- Predictive SLA breach alerts
- Automated refresh scheduling
